# Админ-панель

Адрес входа — `/admin`. В админке можно редактировать каталог блюд и залов, создавать позиции и категории, менять цены и описания, загружать фото, удалять записи, просматривать заказы и заявки, менять их статус. Списки блюд, залов и обращений поддерживают постраничную навигацию.

## Первичная настройка

Панель использует PHP-сессию с HttpOnly/SameSite cookie, CSRF-токеном и хешем пароля администратора. Пароль в репозитории не хранится. Настройте его в уже существующем `~/ohotnik-config.php`, вне каталога сайта:

1. В консоли Jino сгенерируйте хеш. Команда запросит пароль отдельно, он не попадёт в историю команд:

   ```bash
   php -r '$p=readline("Пароль админки: "); echo password_hash($p, PASSWORD_DEFAULT), PHP_EOL;'
   ```

2. Добавьте выведенный хеш в существующий массив `return [...]`:

   ```php
   'admin_password_hash' => 'ВСТАВЬТЕ_ХЕШ_СЮДА',
   ```

   Не создавайте второй `return` и сохраните остальные настройки Make/SMS. У файла должны остаться права `600`.

3. При первом запросе PHP автоматически создаёт `~/ohotnik-data/` с ограниченными правами доступа. Проверьте, что PHP может писать в домашний каталог аккаунта; данные находятся вне публичной папки сайта.

При первом входе исходное меню и список залов копируются в защищённое хранилище. После этого изменения через `/admin` сразу отображаются на сайте без пересборки. Загруженные фото блюд и залов сохраняются в публичной папке изображений, поэтому их URL можно использовать в карточках.

## Заказы и заявки

Принятые после установки обращения записываются в отдельный журнал после успешной отправки уведомления. Старые сообщения из Make/SMS в журнал автоматически не импортируются. Удаление записи окончательное.

Админские изменения из Vite отключены, чтобы локальный прокси к сайту не мог случайно менять production. В локальном превью можно увидеть экран входа; управление становится доступным после публикации кода и настройки `admin_password_hash` на Jino.

Сделайте резервную копию `~/ohotnik-data/` перед ручным переносом или обслуживанием сайта. Скрипт обновления сайта эту папку не трогает.
